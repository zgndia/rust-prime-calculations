# rust-prime-calculations

> Prime number calculations and checks for rust

## Table of Contents

- [Features](#features)
- [Installation](#installation)

- [Tech Stack](#tech-stack)

## Features

- Prime number checks
- Prime number checks for the smallest value > n
- Prime number checks for the biggest value < n
- Prime numbers and it's count that are ≤ n
- Number checks that are only divisible by even numbers and 1 - called "even primes"

## Installation

```bash
git clone https://github.com/username/rust-prime-calculations.git
cd rust-prime-calculations
cargo build
```

## Usage
Run the executable in target/debug or run:
```rust
cargo run
```
